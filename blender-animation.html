Project Overview

In this project, I created a model and animated Solar System using Blender. The animation features the planets orbiting around the sun, demonstrating my skills in 3D modeling, rigging, and animation techniques.

Step-by-Step Procedure

    Manual Procedure

  1. Add a sphere (planet): in Blender press Shift + A → Mesh → UV Sphere, then press S to scale.
  2. Smooth the sphere: select it, right-click → Shade Smooth.
  3. Add a material: open Material Properties, click New (Principled BSDF).
  4. Apply a texture: in Base Color choose Image Texture and load your planet map.
  5. Preview the material: press Z → Material Preview or use the viewport shading icon.
  6. Animate rotation: at frame 1 insert a rotation keyframe (K → Rotation); at frame 250 (or 365) rotate Z by 360° and insert another keyframe.
  7. Add a space background (optional): World Properties → Environment Texture → load a space image.

    Python Scripting Procedure

  1. Open a new script in Blender's Text Editor and write a Python script to create the planet, apply texture, and animate rotation (see provided scripts below).
  2. Run the script to automatically generate the planet with the specified properties and animation.

    Output and Rendering Procedure

  1. To output, go on Output on the Properties tab and change file format to Video, and on Encoding section change Matroshka to MPEG-4
  2. Render the animation: go to Render → Render Animation (or press Ctrl + F12) to export your video.

Each Celestial Body Description

Sun

A massive star at the center of the solar system that provides light and energy to all planets.
Revolution: Orbits the center of the Milky Way galaxy
Orbit period: ~225–250 million years (galactic year)
Distance: ~26,000 light-years from the center of the Milky Way

Mercury

Mercury is the smallest and closest planet to the Sun. It has a rocky, heavily cratered surface and almost no atmosphere, causing extreme temperature changes.
Revolution (Rotation): ~58.6 Earth days
Orbit Period (Year): ~88 Earth days
Distance from Sun: ~57.9 million km

Venus

Venus is similar in size to Earth but has a thick toxic atmosphere made mostly of carbon dioxide. It is the hottest planet due to a strong greenhouse effect.
Revolution (Rotation): ~243 Earth days (retrograde, rotates backward)
Orbit Period (Year): ~225 Earth days
Distance from Sun: ~108.2 million km

Earth

The third planet from the Sun and the only known planet that supports life, with liquid water and an atmosphere.
Revolution: Orbits the Sun
Orbit period: ~365.25 days (1 year)
Distance: ~149.6 million km from the Sun (1 AU)

Moon

Earth’s only natural satellite, responsible for tides and stabilizing Earth’s tilt.
Revolution: Orbits the Earth
Orbit period: ~27.3 days (sidereal period) / ~29.5 days (phase cycle)
Distance: ~384,400 km from Earth

Mars

Mars is known as the “Red Planet” due to iron oxide on its surface. It has the largest volcano in the solar system and signs of ancient water flow.
Revolution (Rotation): ~24.6 hours (similar to Earth)
Orbit Period (Year): ~687 Earth days
Distance from Sun: ~227.9 million km

Mercury Script


import bpy
import math

tex_path = r"INSERT PATH HERE"
space_path = r"INSERT PATH HERE"

# Clean scene
bpy.ops.object.select_all(action='SELECT')
bpy.ops.object.delete(use_global=False)

# Planet
bpy.ops.mesh.primitive_uv_sphere_add(radius=0.4, location=(4, 0, 0))
mercury = bpy.context.active_object
mercury.name = "Mercury"
bpy.ops.object.shade_smooth()

# Material
mat = bpy.data.materials.new("MercuryMat")
mat.use_nodes = True
nodes = mat.node_tree.nodes
links = mat.node_tree.links
nodes.clear()

out = nodes.new("ShaderNodeOutputMaterial")
bsdf = nodes.new("ShaderNodeBsdfPrincipled")
tex = nodes.new("ShaderNodeTexImage")

try:
    tex.image = bpy.data.images.load(tex_path)
    links.new(tex.outputs["Color"], bsdf.inputs["Base Color"])
except:
    pass

links.new(bsdf.outputs["BSDF"], out.inputs["Surface"])
mercury.data.materials.append(mat)

# Animation
mercury.rotation_euler = (0, 0, 0)
mercury.keyframe_insert("rotation_euler", frame=1)

mercury.rotation_euler = (0, 0, math.radians(360))
mercury.keyframe_insert("rotation_euler", frame=88)

if mercury.animation_data is None:
    mercury.animation_data_create()

action = mercury.animation_data.action
if action:
    fcurve = action.fcurve_ensure_for_datablock(
        datablock=mercury,
        data_path="rotation_euler",
        index=2
    )
    for kp in fcurve.keyframe_points:
        kp.interpolation = 'LINEAR'
    fcurve.modifiers.new(type='CYCLES')

# World
world = bpy.data.worlds.new("World") if not bpy.context.scene.world else bpy.context.scene.world
bpy.context.scene.world = world
world.use_nodes = True

wnodes = world.node_tree.nodes
wlinks = world.node_tree.links
wnodes.clear()

wout = wnodes.new("ShaderNodeOutputWorld")
wbg = wnodes.new("ShaderNodeBackground")
wtex = wnodes.new("ShaderNodeTexEnvironment")

wtex.image = bpy.data.images.load(space_path)

wlinks.new(wtex.outputs["Color"], wbg.inputs["Color"])
wlinks.new(wbg.outputs["Background"], wout.inputs["Surface"])

Earth Script


import bpy
import math

# ============================================
# TEXTURE PATHS
# ============================================
earth_texture_path = r"INSERT YOUR OWN HERE"
space_texture_path = r"INSERT YOUR OWN HERE"

# ============================================
# CLEAN SCENE
# ============================================
bpy.ops.object.select_all(action='SELECT')
bpy.ops.object.delete(use_global=False)

# ============================================
# CREATE EARTH
# ============================================
bpy.ops.mesh.primitive_uv_sphere_add(radius=1, location=(0, 0, 0))
earth = bpy.context.active_object
earth.name = "Earth"

bpy.ops.object.shade_smooth()

# ============================================
# EARTH MATERIAL
# ============================================
mat = bpy.data.materials.new(name="EarthMaterial")
mat.use_nodes = True

nodes = mat.node_tree.nodes
links = mat.node_tree.links
nodes.clear()

output = nodes.new(type='ShaderNodeOutputMaterial')
bsdf = nodes.new(type='ShaderNodeBsdfPrincipled')
tex = nodes.new(type='ShaderNodeTexImage')

tex.image = bpy.data.images.load(earth_texture_path)

links.new(tex.outputs['Color'], bsdf.inputs['Base Color'])
links.new(bsdf.outputs['BSDF'], output.inputs['Surface'])

earth.data.materials.append(mat)

# ============================================
# ANIMATION SETUP
# ============================================
bpy.context.scene.frame_start = 1
bpy.context.scene.frame_end = 365

# Clear rotation
earth.rotation_euler = (0, 0, 0)
earth.keyframe_insert(data_path="rotation_euler", frame=1)

# Full rotation (1 year simulation)
earth.rotation_euler = (0, 0, math.radians(360))
earth.keyframe_insert(data_path="rotation_euler", frame=365)

# ============================================
# SAFE FCURVE HANDLING (BLENDER 5+)
# ============================================
if earth.animation_data is None:
    earth.animation_data_create()

action = earth.animation_data.action

if action:
    # Ensure Z rotation fcurve exists safely
    fcurve = action.fcurve_ensure_for_datablock(
        datablock=earth,
        data_path="rotation_euler",
        index=2
    )

    # Make motion constant speed (no easing)
    for kp in fcurve.keyframe_points:
        kp.interpolation = 'LINEAR'

    # Make it loop forever (Cycles modifier)
    fcurve.modifiers.new(type='CYCLES')

# ============================================
# WORLD (SPACE BACKGROUND)
# ============================================
world = bpy.context.scene.world
if world is None:
    world = bpy.data.worlds.new("World")
    bpy.context.scene.world = world

world.use_nodes = True

wnodes = world.node_tree.nodes
wlinks = world.node_tree.links
wnodes.clear()

w_output = wnodes.new(type='ShaderNodeOutputWorld')
w_bg = wnodes.new(type='ShaderNodeBackground')
w_tex = wnodes.new(type='ShaderNodeTexEnvironment')

w_tex.image = bpy.data.images.load(space_texture_path)

wlinks.new(w_tex.outputs['Color'], w_bg.inputs['Color'])
wlinks.new(w_bg.outputs['Background'], w_output.inputs['Surface'])

import bpy
import math

# ============================================
# TEXTURE PATHS
# ============================================
sun_texture_path = r"INSERT YOUR PATH HERE"
space_texture_path = r"INSERT YOUR PATH HERE"

# ============================================
# CLEAN SCENE
# ============================================
bpy.ops.object.select_all(action='SELECT')
bpy.ops.object.delete(use_global=False)

# ============================================
# CREATE SUN
# ============================================
bpy.ops.mesh.primitive_uv_sphere_add(radius=1, location=(0, 0, 0))
sun = bpy.context.active_object
sun.name = "Sun"

sun.scale = (2, 2, 2)
bpy.ops.object.shade_smooth()

# ============================================
# SUN MATERIAL (EMISSION + TEXTURE)
# ============================================
mat = bpy.data.materials.new(name="SunMaterial")
mat.use_nodes = True

nodes = mat.node_tree.nodes
links = mat.node_tree.links
nodes.clear()

output = nodes.new(type='ShaderNodeOutputMaterial')
emission = nodes.new(type='ShaderNodeEmission')
tex = nodes.new(type='ShaderNodeTexImage')

try:
    tex.image = bpy.data.images.load(sun_texture_path)
    links.new(tex.outputs['Color'], emission.inputs['Color'])
except:
    pass

emission.inputs['Strength'].default_value = 10

links.new(emission.outputs['Emission'], output.inputs['Surface'])

sun.data.materials.append(mat)

# ============================================
# ANIMATION (500 FRAMES)
# ============================================
bpy.context.scene.frame_start = 1
bpy.context.scene.frame_end = 500

sun.keyframe_insert("rotation_euler", frame=1)

sun.rotation_euler = (0, 0, math.radians(360))

# ============================================
# BLENDER 5+ SAFE FCURVE SYSTEM

    sun.animation_data_create()

if world is None:
    world = bpy.data.worlds.new("World")
    bpy.context.scene.world = world

world.use_nodes = True

wnodes = world.node_tree.nodes
